# 📖 독서록 (Book Record)

내가 읽은 책과 독후감을 기록하고 관리할 수 있는 개인 독서 기록 모바일 안드로이드 애플리케이션입니다.

* **반응형 모바일 최적화**: 스마트폰 화면 비율에 최적화된 인터페이스

## 📚 주요 기능 명세

### 1. 홈 화면 (Home)
* **상단 검색창**: 책 제목 또는 작가 이름으로 검색 (대소문자/공백 유연 처리).
* **2열 × 3행 책 카드 그리드**: 최근 독후감이 작성/추가된 책 순서대로 한 화면에 최대 6개의 카드 배치.
* **최신순 정렬**: 과거 날짜로 독서했더라도 새 독후감을 저장한 시점을 기준으로 홈 화면 최상단 갱신.
* **하단 기록 버튼**: 연분홍색의 눈에 띄는 하단 고정 버튼을 통해 손쉽게 새 독후감 작성 페이지로 이동.

### 2. 새 독후감 작성 (Write)
* **책 정보 입력**: 책 제목 및 작가 이름 입력 (필수 항목).
* **독서 날짜 선택**: 기본값 오늘 날짜 설정 및 과거 날짜 선택 지원.
* **장문 독후감 본문**: 줄바꿈 및 문단 구조 완벽 유지.
* **자동 임시 저장 (Auto-draft)**: 입력 중 실수로 창을 닫거나 새로고침해도 작성 중인 내용 복구.
* **도서 자동 매핑**: 동일한 책(제목 + 작가)일 경우 기존 책에 독후감 누적, 새 도서일 경우 신규 생성.

### 3. 책 구분 및 누적 규칙
* **같은 책 기준**: `책 제목`과 `작가 이름`이 모두 일치하는 경우 (앞뒤 공백 정리 후 비교).
* **작가 차이 구분**: 제목이 같더라도 작가가 다르면 서로 다른 독립된 책으로 분류.

### 4. 독후감 열람 및 삭제 (Detail & Delete)
* **누적 독후감 역순 표시**: 가장 최근에 작성된 독후감(독후감 N)이 상단에 배치.
* **⛔ 선택 삭제 기능**:
  * 독후감이 2개 이상인 경우: 삭제할 독후감을 선택하여 해당 기록만 삭제.
  * 마지막 독후감인 경우: 삭제 시 책 기록 및 홈 화면 카드도 함께 자동 삭제.
